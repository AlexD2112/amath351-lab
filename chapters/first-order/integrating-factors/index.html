What does an integrating factor change?

xy′ − 3y = x³,   y(1) = 10.

Read the slope field on both sides of zero, reveal the solution through the initial point, then multiply by the integrating factor. Explore why the initial value at x = 1 determines only the right branch.

A solution before and after multiplying by x⁻³

The lecture fixes C₊ = 10. C₋ is independent; its starting value of 10 is just a display choice. Reveal the curves to see the effect of each slider.

Animation follows increasing x within the selected side. It stops before zero.

Two intervals: (−∞, 0) and (0, ∞). The standard-form slope is undefined at x = 0.

Original equation

y′ = 3y/x + x²

After the integrating factor

1 · Standard form

y′ − (3/x)y = x²

Divide by x on either interval, excluding zero.

2 · Multiply

Choose q(x) = x⁻³

(x⁻³y)′ = 1/x

On x < 0, this is −1 times e−3 ln|x|. A nonzero constant multiple is also a valid integrating factor.

3 · Integrate on each interval

y/x³ = ln|x| + C

Why are the two constants independent, even though both curves approach the origin?

In standard form, P(x) = −3/x and Q(x) = x². Both are continuous on (0, ∞), which contains the initial x = 1. The linear existence and uniqueness theorem gives one solution on that entire interval, not just near x = 1.

On the separate interval (−∞, 0), the same calculation gives y = x³(ln|x| + C₋). The initial value y(1) says nothing about C₋. Try changing C₋ while keeping C₊ = 10: the right branch stays fixed.

For any finite C₋ and C₊, y → 0 and y′ → 0 as x approaches zero from either side. The open circle marks their common limit. No standard-form slope is assigned at x = 0.

The original equation xy′ − 3y = x³ degenerates at x = 0. Setting y(0) = 0 joins these branches into a differentiable solution of that original equation, with y′(0) = 0. Every choice of C₋ works, so continuation through zero is not unique. There is no contradiction: the standard-form uniqueness theorem does not apply across zero.

What changed in the second field?

Multiplying by x⁻³ packages the two terms y′ − 3y/x into the derivative of one quantity, z = x⁻³y. The new slope z′ = 1/x depends only on x: every point in the same vertical column has the same slope. Different initial values translate the z curves vertically.

The transformed graph is z = ln|x| + C on each interval, with independent constants. Unlike y, z tends to −∞ on both sides of zero. The two graphs use different vertical scales. Both use exact formulas, and the moving points have the same x coordinate.
