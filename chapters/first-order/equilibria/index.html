Read the signs before drawing curves

A positive value of f(x) means x increases, so the phase arrow points up. A negative value means x decreases, so it points down. The arrows show direction, not speed.

For x ≠ 0, the factor x² is positive. The sign comes from x² − 4.
State intervalSign of x′Motion
x < −2+↑ toward −2
−2 < x < 0−↓ toward −2
0 < x < 2−↓ toward 0
x > 2+↑ away from 2

−2 attracts from both sides. It is asymptotically stable. 2 repels from both sides. It is unstable. 0 attracts from above and repels from below. We call it semistable; it is not stable with respect to perturbations on both sides.

Equilibria themselves stay fixed. Because f is a polynomial, local uniqueness prevents a solution from crossing an equilibrium solution.

How are the curves calculated?

The curves come from inverting the separated integral on each interval between equilibria:

H(x(t)) = H(x₀) + t,
H(x) = 1/(4x) + (1/16) ln |(x − 2)/(x + 2)|.

For x₀ > 2, H(x) → 0 as x → ∞, so the maximal forward time is T = −H(x₀). The curve ends at blowup. Equilibrium solutions are handled separately.
